# Exercícios Intermediários de C#

Repositório destinado à prática de conceitos intermediários de C#, com exercícios que combinam estruturas de repetição, arrays, métodos, strings e lógica de programação.

## Exercícios

1. Leia um número inteiro e informe se ele é primo ou não.
2. Leia um número `N` e mostre os primeiros `N` números da sequência de Fibonacci.
3. Leia 10 números e mostre o maior, o menor e a média.
4. Leia números até que o usuário digite `0` e mostre a quantidade, os pares, os ímpares e a soma.
5. Leia um número inteiro e mostre o número invertido.
6. Leia uma palavra e informe se ela é um palíndromo.
7. Crie um array com 10 números e mostre apenas os valores que aparecem uma única vez.
8. Crie um array com 10 números e ordene os valores do menor para o maior sem utilizar `Array.Sort()`.
9. Cadastre 5 alunos com nome e três notas e mostre as médias, situações e o aluno com a maior média.
10. Crie um caixa eletrônico que informe a quantidade de notas de R$100, R$50, R$20, R$10, R$5 e R$2 necessárias para um saque.
